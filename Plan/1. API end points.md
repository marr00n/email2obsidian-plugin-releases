## API Documentation

### Authentication
All API endpoints require user authentication. Users can authenticate in two ways:

1. **API Key authentication**: Users can create API keys from the API dashboard and use them via the `x-api-key` header

#### API Keys
- **Creation**: Users can create API keys from the `/api` route in their dashboard
- **Usage**: Include the API key in the `x-api-key` header when making API requests
- **Validation**: API keys are validated in `app/lib/session.server.ts` via the `getUserSession` function
- **Rate limiting**: API keys are subject to rate limiting to prevent abuse
- **Expiry**: API keys can be configured to expire after 3, 5, or 12 months

**Example API request with API key:**
```bash
curl -H "x-api-key: your-api-key-here" https://email2obsidian.com/api/emails
```

### Email Endpoints

#### GET /api/emails
Retrieves a paginated list of emails for the authenticated user.

**Query Parameters:**
- `cursor` (string, optional): Pagination cursor for fetching older emails
- `sort` (string, optional): Sort order, defaults to `date-desc`. Options:
  - `date-desc`: Newest emails first
  - `date-asc`: Oldest emails first
- `tag` (string, optional): Filter emails by hashtag
- `search` (string, optional): Search emails by subject (case-insensitive partial match)

**Response:**
```json
{
  "emails": [
    {
      "id": 1,
      "subject": "Email subject",
      "createdAt": "2025-01-15T10:30:00.000Z",
      "hashtags": ["tag1", "tag2"]
    }
  ],
  "hasMore": true,
  "nextCursor": "2025-01-14T08:20:00.000Z",
  "tags": ["tag1", "tag2", "tag3"]
}
```

#### GET /api/emails/:id
Retrieves a specific email with its attachments for the authenticated user.

**Path Parameters:**
- `id` (integer): Email ID

**Response:**
```json
{
  "id": 1,
  "emailId": "unique-email-id",
  "subject": "Email subject",
  "hashtags": ["tag1", "tag2"],
  "markdownBody": "Email content in markdown format",
  "createdAt": "2025-01-15T10:30:00.000Z",
  "expiresAt": "2025-02-15T10:30:00.000Z",
  "attachments": [
    {
      "id": 1,
      "fileName": "document.pdf",
      "fileSize": 1024000,
      "mimeType": "application/pdf",
      "createdAt": "2025-01-15T10:30:00.000Z",
      "contentDisposition": "inline | attachment"
    }
  ]
}
```

### Attachment Endpoints

#### GET /api/attachments/:id/download
Downloads a specific attachment file for the authenticated user.

**Path Parameters:**
- `id` (integer): Attachment ID

**Response:**
- Returns the file content with appropriate headers:
  - `Content-Type`: MIME type of the file
  - `Content-Length`: File size in bytes
  - `Content-Disposition`: `attachment; filename="filename.ext"`
  - `Cache-Control`: `private, max-age=3600`

### Error Responses for all Endpoints:
- `400`: Invalid attachment ID
- `403`: Access denied (user doesn't own the email containing the attachment)
- `404`: Attachment not found or file not found in storage
- `500`: Error downloading file
